A small Node program that writes one image to `/output/entry.png` — a studio catalogue photograph of an impossible gadget: the REALITY REMOTE RR-1, a matte-black handheld remote that controls reality itself (PAUSE TIME, SKIP MONDAY, MUTE NEIGHBOURS, UNDO SPILL, SUNNY NOW), photographed clean-centred on a seamless grey studio background with exactly one accessory, a plain white coffee mug. Deterministic, no network, no dependencies.

## Run it

```sh
node main.ts
```
